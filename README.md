# Mevindain Website

## Run in VS Code

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost link shown by Vite.

## Add your photos

Open the website and use Gallery > Add Photos. Selected photos are previewed and saved in the current browser using localStorage.

For permanent website photos, replace the files in `public/images/` and update the gallery entries in `src/App.jsx`.
